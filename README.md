# Prime Number Checker in Java

## Description
This Java program checks whether a given number is a prime number. It uses a `for` loop and a conditional statement to determine whether the number has any divisors other than 1 and itself.

## Sample Input
```text
Enter a number: 7
```

## Sample Output
```text
7 is a Prime Number
```

## Concepts Used
- Java programming
- Scanner class for user input
- `for` loop
- `if-else` statements
- Boolean variables
- Modulus operator (`%`)

## How to Run
1. Install the Java JDK.
2. Save the code as `PrimeNumber.java`.
3. Open a terminal in the project folder.
4. Compile the program:
   ```bash
   javac PrimeNumber.java
   ```
5. Run the program:
   ```bash
   java PrimeNumber
   ```

## Example
Input: `8`

Output: `8 is not a Prime Number`
